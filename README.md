# Project Title
Fish Detector
*Recognize Fish for All*

------------------------------------------------------------------------

## Overview

For our ECE 471 Intro to AI and CV final project, we decided to create a real-time fish detection model. The plan was to recognize a variety of fish and jellyfish in real time. 

------------------------------------------------------------------------

## Features

-   Train a YOLO V11 model to detect and classify fish in real time
-   takes an imported image and draws bounding boxes around potential fish and labels them with their names, as well as predicted accuracy


------------------------------------------------------------------------

## Technologies Used

This project utilized Google Colab for initial implementation, then was run locally in Ubuntu Linux for increased iteration speed
